# Test matrix

| Layer | Location | What it proves |
|---|---|---|
| Golden | `tests/golden/` (`pytest -m golden`) | Pinned to independent reference values: NYSE's published 2024 holidays; hand-computed split/dividend total returns; returns, CAGR, volatility, Sharpe, Sortino and drawdown episodes; beta, alpha, tracking error and information ratio against numpy references; historical/Gaussian VaR and ES; the legacy dataset-version hash |
| Unit: calendar | `tests/unit/test_calendar.py` | NYSE holiday observance rules; session counts match published totals (2021–2024) |
| Unit: data | `tests/unit/test_data.py` | As-of adjustment uses no future events; timezone normalization; deterministic synthetic data passes quality; injected defects are detected; content addressing and tamper detection; retries/backoff/throttling; resumable ingestion |
| Property-based | `tests/unit/test_ledger.py` | Random operation sequences never produce negative cash/positions; replay reproduces state; cash equals the sum of cash flows |
| Financial | `tests/unit/test_analytics.py` | Risk-free convention, undefined statistics, FIFO trade stats, VaR/ES, risk contributions, closed-form min-variance, risk parity budgets, infeasibility, stress, Monte Carlo determinism |
| Engine correctness | `tests/unit/test_backtest.py`, `tests/unit/test_engine_pit_adjustment.py` | Zero-cost buy-and-hold equals exact total return; determinism; daily reconciliation for every strategy; constraints; costs reduce wealth; strategies never see future bars; **decisions invariant to truncating future data**; **the strategy's view never shows a split or dividend before its ex-date, and equals the as-of adjustment on every day (fails on a one-bar look-ahead in `scale_as_of`, #164)**; next-open fills; slippage/commission math; split between decision and fill; dividends; delisting; rejections |
| Engine vs reference | `tests/unit/test_engine_oracle.py`, `tests/oracle/` (#180) | An independent reference backtester (`tests/oracle/reference.py`, written from this repo's METHODOLOGY and importing nothing from `quantlab`) keys ticker-level data by instrument itself and agrees with the engine to 1e-9 on every column of the equity record, every trade, rejection, position row and decision, the final ledger's cash and positions, and the meta's session, corporate-action, delisting, zero-volume and stale-mark counts (the list is in `tests/oracle/differential.py`). It is checked on 50 seeded synthetic universes by default and 200 with `QUANTLAB_ORACLE_SLOW=1` (both execution modes, two of five strategies per seed) combining suspensions, zero-volume and unknown-volume bars, splits, reverse splits and dividends (same-day, weekend and in-gap ex-dates, and outside the history), every delisting kind, renames and ticker reuse, short cash, minimum commissions, weight caps, and in a quarter of the seeds a large account (1e8 to 1e12). Since 1.5.0 (#195) the reference's sell proceeds and pro-rata factor are written from METHODOLOGY's text, with the factor found by bisection where the engine solves it in closed form. The affordability cut's 1e-9-share slack, the #196 fit-to-cash cut, and the ledger's limit and float order are still mirrored from the engine (see METHODOLOGY). Twelve hand-computed cases pin both implementations. `QUANTLAB_ORACLE_PROPERTY=1` searches random seeds. `uv run python -m tests.oracle.mutate` injects 32 engine and adjuster defects (the RC assessment's M1–M8 and 24 more), and the suite catches all of them. M33 (#227) keeps the allocators' solver residue: the differential can't see it, because none of its strategies uses an optimizer, and `tests/unit/test_allocator_dust.py` catches it. M34 (#247) drops the look-ahead check's halt exemption: the differential doesn't run the check, and `tests/unit/test_leakage_master.py` catches it. The engine's other unit tests alone miss twelve of them, among them buys before sells, the sell-slippage sign, actions applied after a delisting, the last close not restated across a split, every 1.4.1 and 1.5.0 pro-rata rule, and the 1.6.0 noise-order rule: only the differential catches those. `uv run python -m tests.oracle.ab` records outputs for an A/B of an engine change |
| Reproducibility across processes | `tests/unit/test_reproducibility_processes.py` (`repro_child.py`), `tests/stack/` (#182) | The library chain behind an experiment (backtest, analysis, validation suite, ML run, integrity report, Markdown and HTML report) gives byte-identical outputs in fresh interpreters with `PYTHONHASHSEED` 0, 1, 4242 and random, and BLAS/OpenMP thread counts 1, 2, 4 and the default. The report's `generated_at` is pinned, as the one documented timestamp. The test fails when the ML models lose their random state. `tests/stack/` (opt-in, needs a running app stack and the full-stack lock) reproduces and validates an experiment, restarts the API and worker, and requires the same fingerprint and validation result again |
| Research validation | `tests/unit/test_research.py`, `tests/integration/test_research_api.py` | Grid validity, chronological folds with embargo, walk-forward selects by in-sample Sharpe and tests later windows, monotone cost sweep, PSR/DSR properties, bootstrap determinism, regime partitions, **leakage detector catches a planted adjustment look-ahead**, integrity statuses, validation job via API and integrity before/after validation and reproduction |
| AI evaluation | `tests/unit/test_assistant.py`, `quantlab.assistant.evals`, `tests/integration/test_research_api.py` | 14-question suite: numerical consistency, citation grounding, advice refusal, out-of-scope handling; hallucinating, advice-giving, malformed and failing providers never reach the user; advice questions never reach the model; assistant numbers equal analytics numbers |
| Reports | `tests/integration/test_research_api.py` | HTML/Markdown export from persisted results, script-free, CSP, escaping of user content, fingerprint cited |
| ML pipeline | `tests/unit/test_ml.py`, `tests/integration/test_ml_api.py` | Features identical on data truncated at each date (no look-ahead); labels match forward adjusted returns and become available only after the horizon; purged splits never train on labels overlapping the test window; determinism; metric reference values (perfect, inverted, constant scores); ML run job, idempotency, predictions artifact, isolation |
| Portfolios | `tests/unit/test_valuation.py`, `tests/integration/test_portfolios.py`, `apps/web/e2e/portfolio.spec.ts` | Value conserved through dividends and splits; time-weighted returns exclude cash flows; impossible transactions rejected with the offending entry named and nothing stored; valuation reconciles holdings and cash; risk, stress and Monte Carlo outputs; isolation; browser flow incl. overdraft rejection |
| API contract | `tests/integration/test_api_workflow.py` | OpenAPI, health/readiness, metrics, catalog and bars (cache hit, adjusted), full backtest workflow, P&L attribution reconciles to equity, reproduction fingerprint match, manifests, comparison, idempotency and conflicts, structured validation errors, saved strategies, cancellation, audit |
| Security | `tests/integration/test_security.py` | Auth flows, cookie flags, forged/none-alg/expired tokens, logout-everywhere revocation, role enforcement, last-owner protection, rate limits (per IP, per account failures, atomic reserve, degraded mode), injection-like inputs, security headers, production config guards, metrics token, dataset size limits, cross-workspace isolation |
| Failure injection | `tests/integration/test_jobs_reliability.py` | Duplicate delivery → one result; lease expiry + takeover → stale worker fenced out; reaper requeue and exhaustion; transient retries; permanent failures; cancellation while running and queued; timeouts; no partial results on failure; Redis outage → no lost jobs |
| Migrations | `tests/integration/test_migrations.py` | Downgrade/upgrade round trip; no drift between models and migrations; single head |
| Accessibility | `apps/web/e2e/a11y.spec.ts` | axe-core WCAG 2.0/2.1 A and AA rules on login, register, overview, market data, dataset version, strategy builder, portfolios, ML, compare, settings and experiment results: zero violations |
| Browser E2E | `apps/web/e2e/` | Sign-up, synthetic ingestion, strategy builder, async backtest, results explorer, reproduction match; login errors; auth redirects (desktop + mobile) |

Not yet covered (tracked in ROADMAP.md): performance regression tests, load tests,
