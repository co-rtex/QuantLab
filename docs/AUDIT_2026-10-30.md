# Independent audit, 2026-10-30

Scope: the repository at `1373f53` ("roadmap complete"). Financial core, accounting
invariants, look-ahead, job system and concurrency, authentication across the API's four
uvicorn workers, database operations, web proxy and frontend workflows, Docker and
multi-worktree isolation, benchmark methodology and the assistant evaluation. Earlier
reviews' claims were not taken as evidence: each finding below was reproduced (script,
live stack or failing test) before it was fixed, and each fix has a regression test that
fails on the old code unless noted.

Live checks ran against a second, isolated Compose stack built from this branch
(`quantlab-audit-quantlab`, ports 21400-21411) alongside the main checkout's stack, which
was left untouched.

## Multiple worktrees: assessment

Before: unsafe. `docker-compose.yml` hard-coded `name: quantlab` and host ports, so a
worktree's `make up`/`make app-up` targeted the main checkout's project (rebuilding and
replacing its containers, sharing its volumes) or failed on port conflicts; the
integration suite of every checkout truncated the same `quantlab_test` tables.

After: `scripts/stack-env.sh` (exported by the Makefile) gives each linked worktree its
own Compose project, volumes and a port block; the main checkout keeps its defaults.
Integration tests use a per-worktree database plus a session advisory lock. Verified by
running both stacks concurrently and two concurrent integration sessions. Remaining
shared resources: the Docker daemon's CPU and memory, and the Playwright browser cache
(read-only).
