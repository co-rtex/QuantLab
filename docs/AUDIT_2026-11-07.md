# End-to-end product audit (2026-11-07)

**What was run.** A first-time user's walk through every workflow in a real browser, on
an isolated stack:
* the code: main `bfaa6d9` (engine 1.8.0, validation suite version 3);
* the stack: slot 86, 1 worker, under `scripts/fullstack-lock.sh`.

The workflows: register, overview, a synthetic dataset, the dataset version page, the
experiment builder, a backtest, the results page, the validation suite, the integrity
report, the assistant, reproduction (twice), compare, a portfolio with a transaction,
construction at 100 symbols, an ML run, the HTML report, workspace settings, and a 390 px
viewport. Screenshots are in `.playwright-mcp/` (gitignored).

**Who reviewed it.** The same session that implemented the recent changes. These are its
own observations, not an independent review. Every numeric claim below was checked against
the API's raw values or by hand.

## What worked end to end
* **Synthetic data:** a 100-asset dataset generated in about 6 s. It is labelled synthetic
  on every surface, its quality report has 23 checks, and the instrument list marks
  delistings.
* **Backtests:** the evidence panel shows engine 1.8.0.
* **Validation:**
  * walk-forward, bootstrap intervals, deflated Sharpe, and cost and parameter sweeps;
  * the look-ahead check verified 4 cuts.
* **Integrity report:** it calls the result what it is: an out-of-sample decay, and a
  Sharpe interval that includes 0.
* **Reproduction:** the same output fingerprint as the original (`e95b015747`).
* **Construction:** `mean_variance` at the API's defaults with all 100 symbols now solves
  (#253). 95 symbols are usable after the history filter; the weights sum to 100% within
  the 40% cap.
* **Portfolio:** checked by hand after one buy.
  * Cash: 100,000 − 9,931 + $1,337 of dividends = $91,406.
  * Time-weighted return: −3.27%.
* **ML:** five models with purged chronological folds. The AUCs of 0.49–0.51 are correctly
  read as no skill.
* **Assistant:** answers cite each computed value with its source field.
* **Settings:** roles, invitations, a typed confirmation before deleting a workspace, and
  the audit log.

Checked and **not** defects:
* Gaussian and Cornish-Fisher VaR both showed 1.91%. The raw values are 0.019065 and
  0.019087: at 95% the correction terms nearly cancel.
* A reproduction that looked stuck at "Queued" came from the automation browser's timers.
  The network log shows the page saw completion after 3 polls, and a retest completed in
  under 6 s.

## Fixes
1. **A21 + A20: PR #272.**
   * Images record the commit they were built from, with `-dirty` when the tree had
     uncommitted changes.
   * "unknown" is never equal to anything.
   * Trials count distinct configurations.
   * Verified end to end: an image built from `62d676b` reports `62d676b…`.
2. **A6/A8/A14/A24: PR #273.** `e2e/layout.spec.ts` failed on main for 11 page/width pairs
   and passes on the branch. Full serial E2E: 52/52. Causes, found by measurement:
   * grid items' `min-width: auto` (grid blowout);
   * 14 tables without a scroll container;
   * an `sr-only` cell escaping an unpositioned scroll box;
   * rows that couldn't shrink.
3. **A1, A2, A5, A9, A10, A12, A13, A16, A17, A19:** branch `lead/web-labels`, with
   E2E assertions for A9 and A12 and unit tests for A10.
4. **A18, A22:** open; neither is wrong.
